# 复旦选课占用表

给 **新版** 本科选课页用的浏览器脚本：https://xk.fudan.edu.cn/course-selection/

同学打开自己已经登录的选课页，在右下角点出「无法上课」格子。搜索结果里：

- **占用冲突**（和格子或已选课时间重叠）默认隐藏
- **邯郸 ↔ 枫林连堂**（两门课节次紧贴，且不是第 5 节 12:30 下课到第 6 节 13:30）用琥珀色标成 **无法实现的区域跨越**

不自动选课、不自动刷新、不改提交按钮。

旧仓库 [fudan_xk_extension](https://github.com/singularity-s0/fudan_xk_extension) 绑的是 2021 年的 `.action` 页，对现在这套 Element UI 页面无效。

## 交付是什么

| 给你什么 | 同学怎么拿到 |
| --- | --- |
| 本仓库里的 `fudan-xk-busy.user.js` | 装 [篡改猴 Tampermonkey](https://www.tampermonkey.net/)，用 Raw 地址安装 |
| 可选：`extension/` 目录 | Chrome 加载已解压扩展（不用篡改猴） |
| GitHub 仓库 | 把仓库链接转给同学；不要把 UIS 账号或 Cookie 发给任何人 |

没有单独的网站，也不需要把课表导出给我们。脚本只在 **你的浏览器、你已登录的 xk 页** 上改显示。

## 同学怎么用（约 2 分钟）

1. Chrome / Edge 打开「扩展程序」，打开 **开发人员模式**（篡改猴在 Chrome 上需要，装完最好重启浏览器）。
2. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
3. 打开本仓库的 `fudan-xk-busy.user.js`，点 **Raw**，篡改猴会弹出安装。点安装。
4. 登录 [选课系统](https://xk.fudan.edu.cn/course-selection/) ，进入带 `#/course-select/.../select` 的选课页。
5. 右下角出现 **无法上课时间表**。点格子占住组会、实验、已经决定要上的课。占用格所在校区选邯郸或枫林。
6. 照常搜索课程。红底隐藏的是时间占用；琥珀底带「无法实现的区域跨越」的是邯郸–枫林连堂。

占用格存在你这台电脑的浏览器 `localStorage` 里，清站点数据会丢。

## 判定规则

- 节次 1–14 按学校作息（1=08:00 … 5 节 11:45–12:30，6 节 13:30）。
- **紧贴**：同一天，一门下课节次 +1 = 另一门上课节次。
- **例外**：只有第 5 节 → 第 6 节（12:30–13:30）不算无法跨越，对应午间校车空档。
- 第 10–11 节中间只有 30 分钟，仍标跨越失败。
- 已选课通过页面自带接口只读拉取，与占用表做并集。不会替你点选课。

## 以后怎么加功能

可以加，而且应该加在这个仓库里，不要另起一个绑旧页面的扩展。适合加的：

- 江湾 / 张江 与邯郸的连堂阈值
- 已满课程淡化（只改显示，不要自动点选）
- 按考试形式筛选
- 把占用表同步成可分享的一串格子码

不要加：自动刷新抢课、自动确认提交、打验证码、把 Cookie 传到别人的服务器。

改 `fudan-xk-busy.user.js` 后提高 `@version`，同学更新篡改猴脚本即可。
