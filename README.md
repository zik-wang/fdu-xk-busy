# 复旦选课占用表

给 **新版** 本科选课页用的浏览器脚本：https://xk.fudan.edu.cn/course-selection/

在已登录的选课页上：

- 点格子占住不能上课的节次，搜索结果里与占用/已选课重叠的班次默认隐藏
- 邯郸 ↔ 枫林连堂（节次紧贴，且不是第 5 节 12:30 → 第 6 节 13:30）标成 **无法实现的区域跨越**

不自动选课、不自动刷新、不改提交、不把 Cookie 传到任何服务器。课表数据不出你的浏览器。

旧仓库 [fudan_xk_extension](https://github.com/singularity-s0/fudan_xk_extension) 绑的是 2021 年 `.action` 页，对现在这套页面无效。

## 发给同学（校内论坛只贴这几条）

1. 安装 [篡改猴 Tampermonkey](https://www.tampermonkey.net/)（Edge 商店搜 Tampermonkey 即可）。
2. Edge 打开 `edge://extensions` → 打开 **开发人员模式** → 点开油猴 **详细信息** → 打开 **允许用户脚本**。Chrome 同样要开开发人员模式。
3. 用油猴安装脚本：

https://raw.githubusercontent.com/zik-wang/fdu-xk-busy/main/fudan-xk-busy.user.js

4. 打开选课页按 F5。最上沿出现黄条「复旦选课占用表已运行」才算成功。没有黄条 = 第 2 步没开。

不要发 `D:\` 路径，不要发 `127.0.0.1`，不要要别人的 UIS 账号。

油叉（Greasy Fork）一键安装做好后，把上面第 3 条换成油叉链接即可。

## 本机怎么用

黄条出现后，左上有占用表，按住标题栏可拖走，点复位回到原位。点格子占住组会、实验、已定的课；占用格校区选邯郸或枫林。照常搜索：占用冲突默认隐藏，跨校连堂琥珀色标注。

格子存在这台电脑的 `localStorage`，清站点数据会丢。

## 判定规则

- 节次 1–14 按学校作息（1=08:00 … 5 节 11:45–12:30，6 节 13:30）。
- **紧贴**：同一天，一门下课节次 +1 = 另一门上课节次。
- **例外**：只有第 5 节 → 第 6 节（12:30–13:30）不算无法跨越。
- 第 10–11 节中间 30 分钟，仍标跨越失败。
- 已选课只读拉取，与占用表并集。不会替你点选课。

## 以后怎么加功能

改这个仓库里的 `fudan-xk-busy.user.js`，提高 `@version`，同学更新油猴即可。适合加：江湾/张江连堂、已满淡化、考试形式筛选、占用格分享码。

不要加：自动抢课、自动确认提交、打验证码、把 Cookie 传到别人的服务器。
